# Changelog

## 0.1.0

- First Oxill Maps release based on Obsidian Maps 0.2.2.
- Added configurable command actions with selectable icons in the top-right map control.
- Kept direct note opening on marker left-click and map actions in context menus.
- Added the optional Oxill Forms connector with coordinate prefilling from map and marker context menus.
- Added Russian and English interface text for new features.
